# Structured Information Extraction Agent

An offline-testable agent extracts customer identity, request category and date from synthetic emails into validated structured JSON with review fallback.

An Inkplain practical case: a real project built step by step.

## How this repository works

Every step of the lesson has its own branch, and each one contains all steps up to it:

```bash
git clone https://github.com/Inkplain-Practical-Cases/practical--structured-information-extraction-agent.git
cd practical--structured-information-extraction-agent
git branch -r            # list the step branches
git checkout step-01-…   # code after step 1
```

`main` holds the final, complete version.
